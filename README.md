# Project title: Compact Action Piano
MarinaHack 6.0 Project
Compact Action Piano Web Application would act as a visualizer for a physical piano. The user would connect via Bluetooth and from their movement, the visualizer will display the animation. 

## Roles
|-|-|-|
|Backend Python|Khue Do|
|Frontend HTML|Khue Do|
|3D printing and electronic connection|Alexio Achas|
|Embedded code|Alexio Achas|

## Planned Ideas
• Print a 3D piano with 12 keys (7 lower and 5 upper keys)
• Running the Python Backend file in the background for continuously scanning and connecting to Bluetooth
• Run the embedded code to detect physical piano's movement
• Run the web server while blocking anything might interrupt to listen to the key's pitch while displaying animations along side

## How to run the files
• Open template in VSC or Pycharm for app.py
• Open the website server by clicking the template/index.html file
